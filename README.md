# Կայծ — խաղային վիկտորինաների հարթակ

Իրական ժամանակի վիկտորինաներ՝ ամբողջությամբ հայերենով։ Հաղորդավարը ստեղծում է վիկտորինա և սկսում խաղ, իսկ մասնակիցները միանում են հեռախոսից PIN կոդով՝ առանց գրանցման։

**Տեխնոլոգիաներ.** Next.js 14, Tailwind CSS, Supabase (PostgreSQL, Auth, Realtime, Storage)

## Գործարկում (մոտ 15 րոպե)

### 1. Supabase նախագիծ
1. Գրանցվեք [supabase.com](https://supabase.com)-ում (անվճար) և ստեղծեք նոր նախագիծ։
2. Բացեք **SQL Editor**, պատճենեք `supabase/schema.sql` ֆայլի ամբողջ պարունակությունը և սեղմեք **Run**։
3. **Authentication → Sign In / Providers** բաժնում միացրեք **Allow anonymous sign-ins**։ Առանց դրա մասնակիցները չեն կարողանա միանալ։
4. Արագ փորձարկման համար **Email** բաժնում կարող եք անջատել **Confirm email**-ը։
5. **Project Settings → API** բաժնից պատճենեք **Project URL**-ը և **anon public** բանալին։

### 2. Բանալիներ
Պատճենեք `.env.local.example` ֆայլը որպես `.env.local` և լրացրեք.
```
NEXT_PUBLIC_SUPABASE_URL=https://ձեր-նախագիծ.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ձեր-anon-բանալին
```

### 3. Տեղական գործարկում
Անհրաժեշտ է [Node.js](https://nodejs.org) 18 կամ ավելի նոր տարբերակ։
```
npm install
npm run dev
```
Բացեք http://localhost:3000։ Նույն Wi-Fi ցանցում հեռախոսից միանալու համար օգտագործեք համակարգչի IP հասցեն, օրինակ՝ `http://192.168.1.5:3000`։

### 4. Հրապարակում ինտերնետում (Vercel, անվճար)
1. Վերբեռնեք նախագիծը GitHub։
2. [vercel.com](https://vercel.com)-ում ընտրեք **Add New → Project** և ներմուծեք ռեպոզիտորիան։
3. **Environment Variables** բաժնում ավելացրեք վերևի երկու փոփոխականները և սեղմեք **Deploy**։
4. Supabase-ի **Authentication → URL Configuration** բաժնում **Site URL** դաշտում նշեք ձեր Vercel հասցեն։

## Ինչ կա

| Էջ | Նշանակություն |
|---|---|
| `/` | Գլխավոր էջ |
| `/login` | Մուտք և գրանցում |
| `/dashboard` | Պրոֆիլ, իմ վիկտորինաները, պահվածներ, հանրային գրադարան, պատմություն, վիճակագրություն, որոնում |
| `/create` | Վիկտորինայի խմբագիր՝ բազմընտրանք և ճիշտ/սխալ հարցեր, 2–4 պատասխան, նկար, ժամաչափ, կրկնօրինակում, ջնջում, դասավորություն |
| `/host/[id]` | Հաղորդավարի էկրան՝ PIN, QR կոդ, մասնակիցներ (առցանց կամ անցանց, հեռացում), հարցեր, արդյունքներ, պատվանդան |
| `/join` | Միացում PIN-ով և մականունով |
| `/play/[id]` | Մասնակցի էկրան |
| `/quiz/[id]` | Վիկտորինայի հղումը՝ կիսվելու համար |

### Անվտանգություն և հուսալիություն
- **Ճիշտ պատասխաններ.** պահվում են առանձին աղյուսակում (`game_keys`), և մասնակիցները դրանք չեն տեսնում։
- **Միավորներ.** հաշվվում են սերվերում (`submit_answer`)։ Ճիշտ պատասխանը տալիս է 500–1000 միավոր՝ կախված արագությունից, գումարած շարքի բոնուս՝ մինչև +500։
- **Կրկնակի պատասխաններ.** արգելված են տվյալների բազայի սահմանափակմամբ։
- **Ժամաչափ.** հաշվվում է սերվերի ժամով, այնպես որ բոլոր սարքերը տեսնում են նույն ժամանակը։
- **PIN կոդեր.** եզակի են ակտիվ խաղերի միջև, և միաժամանակ կարող են ընթանալ շատ խաղեր։
- **Կապի խզում.** եթե մասնակիցը թարմացնի էջը կամ կորցնի կապը, նորից կմիանա նույն միավորներով։
